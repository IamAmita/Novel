# 世界に存在する様々な思想一覧

## 【1】政治思想・社会思想

| 思想名 | 概要 |
|--------|------|
| 自由主義 | 個人の自由を最大限尊重し、国家権力の制限を求める思想 |
| 社会主義 | 富や資源の平等な分配を目指す思想 |
| 共産主義 | 私有財産の廃止と階級のない社会を目指す |
| 全体主義 | 個人より国家・組織を優先し、権力を集中する体制 |
| 無政府主義（アナーキズム） | 国家権力を否定し、自発的な協調社会を目指す |
| 保守主義 | 伝統や秩序、歴史的経緯を重視する |
| リベラリズム（進歩主義） | 社会改革や自由な議論を重視する |

## 【2】倫理・道徳思想

| 思想名 | 概要 |
|--------|------|
| 功利主義 | 「最大多数の最大幸福」を目指す |
| カント倫理学（義務論） | 行為そのものの正しさを重視 |
| 徳倫理学 | 美徳を身につけることを重視する |
| 実存主義的倫理 | 個人の選択と責任を重視する |

## 【3】宗教思想・信仰観

| 思想名 | 概要 |
|--------|------|
| 一神教的思想 | 唯一神を信じる（例：キリスト教・イスラム教） |
| 多神教的思想 | 複数の神を信じる（例：日本神道・古代ギリシャ） |
| 無神論 | 神の存在を否定する |
| 汎神論 | 万物に神が宿ると考える |
| 輪廻転生思想 | 生死を繰り返すという世界観（例：仏教・ヒンドゥー教） |

## 【4】哲学的思想・世界観

| 思想名 | 概要 |
|--------|------|
| 実存主義 | 人間の存在と自由、責任を重視する |
| 唯物論 | 物質が根本であるとする |
| 観念論 | 精神や意識が根本であるとする |
| 構造主義・ポスト構造主義 | 言語や構造が人間の認識を規定すると考える |
| 合理主義 | 理性や論理を重視する |
| 経験主義 | 経験や感覚を重視する |

## 【5】経済思想

| 思想名 | 概要 |
|--------|------|
| 資本主義 | 私有財産と市場原理による経済 |
| 社会主義経済 | 国や共同体による経済管理 |
| 重商主義 | 貿易黒字と富の蓄積を重視 |
| 新自由主義 | 規制緩和と市場の自由化を推進 |

## 【6】科学思想・技術思想

| 思想名 | 概要 |
|--------|------|
| 科学的合理主義 | 客観的証拠と論理による真理探求 |
| 技術決定論 | 技術の進化が社会を決定する |
| トランスヒューマニズム | 人間の能力を科学技術で拡張する思想 |

## 【7】その他の思想や価値観

| 思想名 | 概要 |
|--------|------|
| 個人主義 | 個人の権利と自由を重視 |
| 集団主義 | 集団の調和や全体の利益を重視 |
| フェミニズム | 男女平等と女性の権利を重視 |
| 環境主義 | 自然環境の保護と共生を目指す |
