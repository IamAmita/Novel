# Novel

このプロジェクトは自作小説の設定や物語（話）を保存するためのものです。
This project is for storing settings and stories of original novels.

## 作品概要

- **タイトル**：Ray 
- **ジャンル・テーマ**：学園ファンタジー

### 作品のテーマ

- 全ての人間の苦悩
- 生まれは選べない
- 努力と才能、賞賛と嫉妬
- 自由ゆえの不自由
- 勝者と敗者、天国と地獄
