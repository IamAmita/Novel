# メソポタミア文明

西アジアにおける最初期の文明の一つ。チグリス・ユーフラテス川流域で発展した。  
本稿では**魔法が存在する世界線（架空設定）**を中心に解説し、最後に史実ウバイド期を補足する。

## 1. 架空設定：魔法世界線のウバイド期

| 項目 | 魔法がない実史 | 魔法がある場合（仮想シナリオ） |
| ----- | ----------- | ----------------------------------------------------- |
| 基本資源 | 灌漑・農耕・家畜 | **物質魔法**で運河を"錬成"、 **探知魔法**で地下水脈を即発見 |
| 社会指導層 | 祭司＋長老 | 祭司兼"高等魔術師"<br>（領域・死霊魔法の使い手） |
| 建築 | 粘土煉瓦の家＆小神殿 | **物理魔法**で日干し煉瓦を量産し巨大基壇を短期構築 |
| 宗教観 | 祖霊・自然信仰 | 神＝「別世界の存在」への理解が早期に体系化<br>死霊魔法で"祖霊顕現祭"が年中行事に |
| 集落規模 | 村落レベル（数百人） | 神殿都市化が前倒し：エリドゥ2,000人規模→5,000人規模へ |
| 技術・交易 | 土器・銅器導入準備段階 | 探知魔法で鉱脈を見つけ**メソポタミア初の銅器文化が前倒し**<br>長距離キャラバン護衛に領域魔法を活用 |

---

### 1. 農業・灌漑へのインパクト

* **物質魔法**で土を硬化させた堤防、瞬時に開閉できる"エーテル閘門"を構築。
* **探知魔法**を持つ10%の魔術師が「水位管理チーム」として各運河を巡回。
  → 旱魃・洪水被害が劇的に減り、農業余剰が *紀元前5500年* 頃から発生。

### 2. 階層社会の早期出現

* 高等魔術師（領域・死霊）は神官と同一身分へ統合。
* エーテル貯蔵量が大きい者ほど神殿での地位が上がり、「魔力譜」という戸籍様式が誕生。
* **エリドゥ神殿**は"聖域領域"を常時展開し、外敵（野生動物・略奪民）を排除。周囲の村落が吸収され、都市化ペースが実史より約500年早まる。

### 3. 宗教・神話の進化

* 死霊魔法の公開儀式により、祖先の声が可視化される → 神と祖霊の区別が生まれ、階層化された"霊系図"信仰が成立。
* 「神＝高次元へ去った魔術師」という観念が芽生え、別世界との往来伝承がウルク期の冥界神話に直結。

### 4. 交易ネットワーク

* 探知隊がトルコ南東部の銅鉱脈を発見 → **銅斧・銅鏃**を生産できる"冶金魔術ギルド"が誕生。
* 領域魔法で結界を張った"キャラバン宿"が主要路に点在し、長距離交易（黒曜石・松脂）が活発化。
* 経済余剰＋魔法護衛により、**「王の道」的な安全走廊**がウルク期以前から機能。

### 5. 都市計画と建築

* 物理魔法で煉瓦を"連続硬化"→ 重機不要のため、高さ10 m級の段状基壇が建設可能。
* ジッグラトの原型がウバイド末期（実年で前4500頃）には出現し、周辺都市が競って神殿を拡大。
* 都市景観は早くも多層構造化し、後のウルク期都市の規模感を先取り。

### 6. 技術と魔法の共存・緊張

* **下等魔法（物質・物理）**が石器や単純道具と競合し、手工業者は"魔法鍛冶"と融合。
* 逆に、**魔力の代償（疲弊・神経摩耗）**を抑えるため、省エネな機械的手段（滑車・車輪）が発明される動機も強まる。
* この"手段の二重化"が技術革新を加速させ、**楔形文字の発明が実史より200年早まる**可能性。

## 2. 架空設定：魔法世界線のウルク期

### 位置づけ
ウバイド末期で"魔力インフラ"が整った結果、
①人口増・②物流拡大・③防衛力向上が同時に進行。
これが "都市" という新たな社会装置を一気に跳躍進化させる。

| 前都市期 | 前4500-4300 | 神殿拡張ラッシュ | 8-10 | エリドゥ≈6千 |

神殿だけでなく"領域結界で囲う居住区"が都市の境界を決める。

### 新しい社会・政治システム

#### 1. 結界外交
都市-都市の領域を部分重ねて"共鳴回廊"を作り、通商協定を物理的に固定
→ 同盟更新時は結界の再接合＝盛大な儀式＝政治パフォーマンス。

#### 2. 王権の誕生（都市国家期）
* 領域権限を握る "上級領域司" が軍事部門を兼務し、
神殿評議会から半独立 → "ルガル（王）"と自称。
* 死霊魔術師は立法監査役となり、祖霊裁定で王権を制限。
→ 二重権力構造が都市国家の標準モデルに。

#### 3. 軍事魔術革新
* 物質魔法式"連続鋳造" で銅短剣大量生産。
* 領域結界を野戦投射する"移動領域盾"登場（前3400頃）。
* 魔力少数精鋭＋大量歩兵の複合編制が確立。

## 3. 史実補足：ウバイド期（紀元前6500年～前4000年）

ウバイド期はメソポタミア文明の最初期にあたり、農耕と定住社会が確立した時代である。

### 概要

| 項目 | 内容 |
| --- | --- |
| 時期 | 紀元前6500年～紀元前4000年頃 |
| 地域 | 南メソポタミア（エリドゥ・ウル・ウルク周辺） |
| 文化の特徴 | 灌漑農業、定住集落、神殿建築、彩文土器 |

### 主な特徴

1. **農業と灌漑の発展**  
   チグリス・ユーフラテス川流域で灌漑農業が始まり、小麦・大麦の栽培や家畜飼育が行われた。  
2. **集落と社会組織**  
   エリドゥに代表される定住集落が形成され、日干し煉瓦の家屋が立ち並んだ。社会分業と階層化の萌芽が見られる。  
3. **宗教と神殿の原型**  
   エリドゥ神殿は最古の神殿遺構で、後のジッグラトの原型となる。祭司が政治・宗教の中心を担った。  
4. **土器文化（ウバイド土器）**  
   緑がかった彩文土器が普及し、高度な焼成技術が示される。  
5. **交易と文化の拡散**  
   南メソポタミアの文化が北メソポタミアやイラン高原へ広がり、同様の土器が各地で出土する。
