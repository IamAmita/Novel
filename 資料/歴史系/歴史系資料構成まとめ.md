## 時代区分詳細

### 先史時代
- **旧石器時代**: 約300万年前〜約1万年前
- **新石器時代**: 約1万年前〜約5000年前
- **金属器時代**: 約5000年前〜紀元前3000年頃

### 古代
- **初期王朝時代**: 紀元前3000年頃〜紀元前2000年頃
- **古典古代**: 紀元前2000年頃〜紀元前500年頃
- **ヘレニズム時代**: 紀元前323年〜紀元前30年
- **ローマ帝国時代**: 紀元前27年〜476年

### 中世
- **初期中世**: 476年〜1000年頃
- **高度中世**: 1000年頃〜1300年頃
- **後期中世**: 1300年頃〜1500年頃

### 近世
- **ルネサンス**: 14世紀〜17世紀
- **大航海時代**: 15世紀〜17世紀
- **宗教改革**: 16世紀
- **絶対王政時代**: 17世紀〜18世紀

### 近代
- **産業革命期**: 1760年〜1840年
- **市民革命期**: 1775年〜1848年
- **帝国主義時代**: 1870年〜1914年

### 現代
- **第一次世界大戦**: 1914年〜1918年
- **戦間期**: 1918年〜1939年
- **第二次世界大戦**: 1939年〜1945年
- **冷戦時代**: 1947年〜1991年
- **ポスト冷戦時代**: 1991年〜現在

## 地域区分詳細

### ヨーロッパ
- **西ヨーロッパ**: フランス、ドイツ、イギリス、スペイン、ポルトガル、ベネルクス三国
- **東ヨーロッパ**: ロシア、ポーランド、ハンガリー、チェコ、スロバキア、バルカン諸国
- **南ヨーロッパ**: イタリア、ギリシャ、バルカン半島諸国
- **北ヨーロッパ**: スカンディナビア諸国（ノルウェー、スウェーデン、デンマーク、フィンランド）、バルト三国

### アジア
- **東アジア**: 中国、日本、朝鮮半島（韓国、北朝鮮）、モンゴル
- **東南アジア**: インドシナ（ベトナム、ラオス、カンボジア）、タイ、マレーシア、インドネシア、フィリピン、シンガポール、ブルネイ
- **南アジア**: インド、パキスタン、バングラデシュ、スリランカ、ネパール、ブータン、モルディブ
- **中央アジア**: カザフスタン、ウズベキスタン、キルギス、タジキスタン、トルクメニスタン
- **西アジア（中東）**: トルコ、イラン、イラク、サウジアラビア、イスラエル、レバノン、シリア、ヨルダン、クウェート、アラブ首長国連邦、オマーン、イエメン

### アフリカ
- **北アフリカ**: エジプト、リビア、チュニジア、アルジェリア、モロッコ、スーダン
- **サハラ以南アフリカ**: 西アフリカ、東アフリカ、中央アフリカ、南アフリカの各地域

### アメリカ大陸
- **北アメリカ**: アメリカ合衆国、カナダ、メキシコ
- **中央アメリカ**: グアテマラ、ホンジュラス、エルサルバドル、ニカラグア、コスタリカ、パナマ、ベリーズ
- **南アメリカ**: ブラジル、アルゼンチン、チリ、ペルー、コロンビア、ベネズエラ、エクアドル、ボリビア、パラグアイ、ウルグアイ、ガイアナ、スリナム、フランス領ギアナ

### オセアニア
- オーストラリア、ニュージーランド、太平洋諸島（ポリネシア、メラネシア、ミクロネシア）

### 極地・その他
- 北極圏、南極大陸、その他の地域

## 作成過程

### 1. 基本構造の作成
- 歴史系フォルダの作成
- 時代区分フォルダの作成（先史時代、古代、中世、近世、近代、現代）

### 2. 詳細時代区分の追加
- 各時代の詳細区分を追加
- 例：先史時代→旧石器時代、新石器時代、金属器時代

### 3. 地域区分の追加
- 各詳細時代区分の下に地域フォルダを作成
- ヨーロッパ、アジア、アフリカ、アメリカ大陸、オセアニア、極地・その他

### 4. 神話フォルダの追加
- ├── 0_神話/
- 地域区分を適用

### 5. 調査プランの作成
- 体系的な調査方法の策定
- 優先度とスケジュールの設定

## 利用方法

### 資料の配置
```
[時代]/[詳細時代]/[地域]/[サブ地域]/[ファイル名].md
例: 古代/古典古代/アジア/東アジア/中国王朝.md
```

### ファイル命名規則
```
[時代]_[地域]_[項目]_[詳細].md
例: 古代_東アジア_政治制度_中国王朝.md
```

### 資料構造
1. **概要**: 基本的な情報
2. **詳細**: 具体的な内容
3. **参考文献**: 情報源
4. **関連項目**: 他の時代・地域との関連
5. **創作への応用**: 小説での活用方法

## 注意事項

1. **歴史的公正性**: 偏見のない客観的な記述を心がける
2. **文化的配慮**: 各文化への敬意と理解を保つ
3. **創作の自由**: 歴史的事実を基にしつつ、創作の自由を保つ
4. **継続的学習**: 新しい発見・研究への対応を継続する
