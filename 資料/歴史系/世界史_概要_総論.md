# 世界史 概要 総論

## 概要

本稿は先史時代から現代に至るまでの世界史を、主要トピックと年表形式で一望できる「鳥瞰図」としてまとめたものである。各時代の詳細は個別ファイルに譲り、ここでは連続性・因果関係・グローバルな相互作用に焦点を当てる。

## 詳細

### 1. 時代別ハイライト

| 時代 | 期間 (目安) | キーワード | 代表的出来事 |
|------|--------------|-------------|---------------|
| 先史時代 | ～前 3000 頃 | 狩猟採集 → 農耕牧畜 | 新石器革命、金属器の利用開始 |
| 古代 | 前 3000 頃～ 5 C | 都市国家・帝国、宗教・哲学 | メソポタミア・エジプト文明、アケメネス朝、ギリシャ・ローマ、秦漢、中国、仏教・キリスト教成立 |
| 中世 | 5 C～15 C | 封建制度、教権、イスラム拡大 | 十字軍、宋・元、ハンザ同盟、モンゴル帝国、百年戦争、ルネサンス前夜 |
| 近世 | 15 C～18 C | 大航海・ルネサンス・宗教改革 | 新大陸発見、絶対王政、科学革命、啓蒙思想、植民地帝国 |
| 近代 | 18 C～1991 | 産業化・国民国家・世界大戦 | 産業革命、フランス革命、帝国主義、第一次・第二次世界大戦、冷戦 |
| 現代 | 1991～現在 | グローバル化・情報化 | インターネット、テロとの戦い、気候変動、多極化 |

### 2. テーマ別縦断

1. **技術革新**: 打製石器 → 農耕 → 金属器 → 蒸気機関 → 電力 → デジタル革命。
2. **国家形態**: 首長制 → 王朝 → 帝国 → 封建領主制 → 絶対王政 → 国民国家 → 超国家機構 (EU 等)。
3. **経済システム**: 自給自足 → 商業資本 → 重商主義 → 産業資本 → 修正資本 → グローバル資本。
4. **宗教・思想**: 多神教 → 世界宗教の拡大 → 宗教改革・啓蒙 → 世俗化と多元化。
5. **戦争と平和**: 部族間抗争 → 帝国征服 → 宗教戦争 → 世界大戦 → 冷戦 → テロ・局地紛争。

### 3. 年表 (簡易)

- c. 10,000 BCE: 新石器革命 (農耕開始)
- c. 3,100 BCE: エジプト統一王朝成立
- c. 776 BCE: 古代オリンピック開始
- 27 BCE: ローマ帝国成立
- 476 CE: 西ローマ帝国滅亡 → 中世開始
- 622: イスラム暦元年 (ヒジュラ)
- 1096–1291: 十字軍遠征
- 1453: コンスタンティノープル陥落
- 1492: コロンブス新大陸到達
- 1517: ルター宗教改革
- 1648: ウェストファリア条約
- 1776: アメリカ独立宣言
- 1789: フランス革命
- 1804: 蒸気機関車試運転
- 1914–1918: 第一次世界大戦
- 1939–1945: 第二次世界大戦
- 1945–1991: 冷戦時代
- 1969: 月面着陸
- 1991: ソ連崩壊 (冷戦終結)
- 2001: 9.11 同時多発テロ
- 2020: 新型コロナパンデミック

## 創作への応用
- **年表の活用**: 物語の時代背景を設定する際に、同時代の他地域イベントを参照してリアリティを向上。
- **因果の連鎖**: 技術革新 → 社会変動 → 文化形成 のパターンをプロットメイクに応用。
- **もしも歴史**: 重要転換点 (例: ウェストファリア条約、産業革命) を分岐として代替歴史を構築。
