# 近代 世界 概要 総論

## 概要

近代（Modern Period）は、おおむね 18 世紀後半の産業革命以降から 1991 年の冷戦終結までを指す。工業化と国民国家の確立、二度の世界大戦、イデオロギー対立と脱植民地化、情報化と大衆社会の形成など、世界秩序が劇的に再編された時代である。本稿では 3 期（初期／中期／後期）に区分し、主要テーマ・地域動向を概観する。

## 詳細

### 1. 時期区分

| 区分 | 概年 | 主な出来事・特徴 |
|------|------|------------------|
| **初期近代** | 18 世紀後半〜 1914 年 | 産業革命の開始／国民国家と帝国主義の形成 |
| **中期近代** | 1914 年〜 1945 年 | 二度の世界大戦／ロシア革命・ファシズムの台頭 |
| **後期近代** | 1945 年〜 1991 年 | 冷戦構造／脱植民地化／高度経済成長と社会資本主義・資本主義の競合 |

### 2. 主要テーマ・特徴

#### 2-1. 政治・国家体制
- **国民国家の成立**: フランス革命 (1789) を契機に主権在民と憲法理念が拡散。
- **帝国主義と植民地主義**: 19 世紀後半、列強がアフリカ・アジアを分割支配。米・日も海外進出。
- **全体主義の台頭**: ソヴィエト連邦樹立 (1917)、イタリア・ドイツのファシズム政権 (1920–30s)。

#### 2-2. 経済・産業
- **産業革命**: 蒸気機関・鉄道・紡績機械 (18C) → 電力・化学 (19C) → 自動車・石油 (20C)。
- **資本主義の変容**: 自由主義 → 修正資本主義 (福祉国家) → 新自由主義 (1980s)。
- **世界経済システム**: 金本位制 → ブレトン・ウッズ体制 (1944) → 変動相場制 (1971)。

#### 2-3. イデオロギー・社会運動
- **自由主義 vs 社会主義**: マルクス主義の影響下で労働運動・社会主義政党が勃興。
- **ナショナリズム・独立運動**: 19C ラテンアメリカ、20C アジア・アフリカで植民地解放。
- **市民権運動・フェミニズム**: 普通選挙、ブラックパワー、女性参政権 (英 1918, 米 1920) など。

#### 2-4. 科学・技術・文化
- **技術革新**: 電気・電話・飛行機・核技術・半導体・宇宙開発。
- **情報化**: 活版 → 新聞 → ラジオ → テレビ → コンピュータ → インターネット (1960–90s)。
- **大衆文化**: 映画 (1895–)、ポピュラー音楽、スポーツ産業、消費文化のグローバル化。

### 3. 地域別ポイント

| 地域 | 主な動向 |
|------|----------|
| **ヨーロッパ** | 大英帝国の覇権／帝国主義競争 → 世界大戦による国境再編 → ECSC・EEC から EU へ統合 |
| **北アメリカ** | 米国の工業化と世界警察的役割、カナダ自治拡大・福祉国家化 |
| **アジア** | 日本の明治維新と帝国化、清朝崩壊→中華民国→中華人民共和国、インド・東南アジア独立運動 |
| **アフリカ** | ベルリン会議 (1884–85) で分割 → 第二次大戦後に急速な脱植民地化・民族国家建設 |
| **ラテンアメリカ** | ボリバル・サンマルティンらの 19C 独立、20C 軍事政権と米州機構、資源ナショナリズム |

### 4. 近代の終焉と現代への橋渡し
- **冷戦終結 (1991)**: ソ連崩壊により二極体制が崩壊、多極化・グローバリズムへ。
- **グローバル資本主義の深化**: デジタル経済・金融統合・サービス化の進展。
- **国際機関の役割拡大**: 国連、WTO、EU、IMF などが経済協調・紛争解決を推進。
