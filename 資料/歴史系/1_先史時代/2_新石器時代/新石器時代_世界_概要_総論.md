# 新石器時代 世界 概要 総論

## 概要

新石器時代（Neolithic Age）は、**約1万年前（紀元前9000年頃）から紀元前3000年頃まで**続いた時代で、人類が本格的に**農耕と牧畜**を開始したことが最大の特徴である。**磨製石器**や**土器**の使用も始まり、狩猟採集から生産経済への転換、定住生活の開始、村落の形成など、人類史における画期的な変革期である。この時代の変化は「**新石器革命**」と呼ばれ、現代文明の基盤を築いた。

## 詳細

### 特徴（総覧）

| 項目 | 内容 |
|------|------|
| **時期** | 約1万年前（紀元前9000年頃）〜 紀元前3000年頃 |
| **生活様式** | 定住生活の開始、農耕（穀物栽培）、牧畜（動物の飼育） |
| **主要道具** | 磨製石器（石斧・石鍬・石鎌）、弓矢、土器、織物 |
| **食料生産** | 生産経済（狩猟採集から農耕牧畜への転換） |
| **住居** | 村落の形成（定住）、竪穴住居・平地住居 |
| **社会構造** | 余剰生産物の発生 → 貧富・階級の分化の始まり |
| **宗教・文化** | 祖先崇拝、神殿・祭祀の場、巨石文化（メガリス） |
| **人口増加** | 農耕による食料の安定供給で人口が急増 |
| **技術革新** | 土器製作、織物、建築技術の発達 |

### 農耕と牧畜の起源（地域別）

| 地域 | 主な栽培植物・家畜 | 特徴 |
|------|------------------|------|
| **西アジア（肥沃な三日月地帯）** | 小麦、大麦、羊、山羊 | 世界最古級の農耕文化 |
| **東アジア（中国）** | 稲（長江流域）、粟（黄河流域）、豚 | 稲作文化の起源 |
| **中南米** | トウモロコシ、ジャガイモ、リャマ | 独自の農耕文化 |
| **アフリカ** | モロコシ（ソルガム）、ヤムイモ | 熱帯適応型農耕 |
| **ヨーロッパ** | 小麦、大麦、牛、豚 | 西アジアからの伝播 |

### 代表的な遺跡・文化

| 遺跡・文化 | 場所 | 特徴 |
|-----------|------|------|
| **イェリコ** | パレスチナ | 世界最古級の城壁都市（紀元前8000年頃） |
| **チャタル・ヒュユク** | トルコ | 大規模な集落跡、壁画、神殿 |
| **ストーンヘンジ** | イギリス | 巨石文化の代表例 |
| **縄文文化** | 日本 | 土器文化、竪穴住居、貝塚 |
| **仰韶文化** | 中国 | 彩文土器、農耕村落 |

### 文化的特徴

- **土器の使用**：食料の保存や調理に使用（日本では縄文土器など）
- **織物の発明**：植物繊維の利用、衣服の製作
- **宗教的施設の出現**：神殿や祭祀場、祖先崇拝
- **巨石文化（メガリス）**：ドルメン（支石墓）、メンヒル（立石）、ストーンヘンジなど
- **装飾品の発達**：玉類、貝殻装飾、土偶など

### 新石器時代の終焉と次期への移行

新石器時代は、金属器（銅や青銅）の使用が始まる**青銅器時代**の到来によって終わる。この時代区分の変化は地域によって時期が異なるが、概ね**紀元前3000年頃**が目安である。金属器の使用により、より効率的な農具や武器が作られるようになり、社会の階層化がさらに進展した。

## 創作への応用

- **世界観設定**：農耕民と狩猟採集民の境界地域を舞台にした文化衝突と交流。
- **キャラクター造形**：農耕技術を伝える旅人、土器職人、祭祀を司るシャーマンなど、専門職の分化を反映した役割設定。
- **プロット装置**：農耕開始による食料余剰を巡る部族間対立や、新技術の導入による価値観の変化を物語の転換点に活用。
- **社会構造**：余剰生産物による階層分化、専門職の出現を通じた社会変革の描写。
- **精神文化**：祖先崇拝や巨石文化を「魔法の体系化」として解釈し、宗教・呪術体系の構築に応用。
