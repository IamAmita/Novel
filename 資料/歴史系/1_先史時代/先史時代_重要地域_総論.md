# 先史時代 重要地域 総論

## 概要

先史時代における人類の歴史的進化と文明の発展を地域別に整理し、各時代における重要地域の特徴・遺跡・文化を概観する。人類の拡散から農耕革命、そして都市文明の誕生まで、地域ごとの発展パターンと相互影響を明らかにする。

## 詳細

### 旧石器時代（約250万年前～約1万年前）

| 地域 | 重要事項・遺跡 | 特徴 |
|------|---------------|------|
| **アフリカ** | 人類発祥の地（ホモ・ハビリス、ホモ・エレクトス）、オルドヴァイ峡谷 | 人類進化の中心地、最古級の石器文化 |
| **ヨーロッパ** | クロマニョン人、ラスコー洞窟・アルタミラ洞窟（壁画） | 芸術文化の発達、ネアンデルタール人との共存 |
| **アジア** | ジャワ原人（インドネシア）、北京原人（中国） | ホモ・エレクトスの東進、火の使用 |
| **日本列島** | 旧石器時代人（岩宿遺跡など） | 後期旧石器文化、細石刃文化 |

### 新石器時代（約1万年前～紀元前3000年頃）

| 地域 | 重要事項・遺跡 | 特徴 |
|------|---------------|------|
| **西アジア（肥沃な三日月地帯）** | 農耕・牧畜の開始、イェリコ、チャタル・ヒュユク | 世界最古級の農耕文化、都市の萌芽 |
| **東アジア（中国）** | 黄河流域（粟作）、長江流域（稲作）、仰韶文化、竜山文化 | 独自の農耕文化、彩文土器文化 |
| **南アジア（インド周辺）** | メールガル遺跡（農耕村落） | インダス文明の前段階 |
| **ヨーロッパ** | 巨石文化（メンヒル・ドルメン）、新石器村落 | 西アジアからの農耕伝播、巨石記念物 |
| **中南米** | トウモロコシ栽培、ギラ川流域 | 独自の農耕文化の発展 |
| **日本列島** | 縄文時代（縄文土器、磨製石器、定住生活） | 土器文化、貝塚、竪穴住居 |

### 金属器時代（紀元前4500年頃～紀元前1000年頃）

| 地域 | 重要事項・文明 | 特徴 |
|------|---------------|------|
| **西アジア** | メソポタミア文明（シュメール、ウル、ウルク）、青銅器文化 | 楔形文字、都市国家、青銅器文化の中心 |
| **エジプト** | 古王国時代（ピラミッド）、青銅器文化 | ヒエログリフ、中央集権国家 |
| **インダス文明** | モヘンジョ・ダロ、ハラッパー（青銅器使用） | 都市計画、印章文字 |
| **中国** | 殷王朝（高度な青銅器文化） | 甲骨文字、青銅器文化 |
| **ヨーロッパ** | ミケーネ文明（青銅器）、ケルト鉄器文化 | 宮殿文化、鉄器文化 |
| **日本列島** | 弥生時代（青銅器・鉄器の使用、水稲農耕） | 大陸文化の影響、水稲農耕 |
| **中南米** | アンデス高地で銅器文化 | 独自の金属器文化（本格化は後世） |

## 地域別発展パターン

### 技術伝播の流れ

1. **アフリカ発祥**：人類の起源と石器技術
2. **西アジア中心**：農耕革命と都市文明の誕生
3. **各地域への拡散**：独自文化の形成と地域間交流

### 文化圏の形成

- **西アジア文化圏**：メソポタミア・エジプト・インダス
- **東アジア文化圏**：中国・朝鮮・日本
- **ヨーロッパ文化圏**：地中海・北欧・東欧
- **アメリカ文化圏**：独自発展の農耕・金属器文化

## 時代別特徴の比較

| 時代 | 主な地域 | 特徴 |
|------|---------|------|
| **旧石器時代** | アフリカ、ヨーロッパ、アジア、日本 | 狩猟採集、打製石器、洞窟壁画 |
| **新石器時代** | 西アジア、中国、インド、中南米、日本 | 農耕牧畜、磨製石器、土器、村落形成 |
| **金属器時代** | 西アジア、エジプト、インダス、中国、ヨーロッパ、日本 | 青銅器・鉄器、国家形成、都市文明 |

## 重要な転換点

### 技術革新の波

1. **石器技術**：打製石器 → 磨製石器 → 金属器
2. **生業の転換**：狩猟採集 → 農耕牧畜 → 都市経済
3. **社会組織**：小集団 → 村落 → 都市国家

### 地域間交流の深化

- **旧石器時代**：人類の拡散と地域適応
- **新石器時代**：農耕技術の伝播と地域文化の形成
- **金属器時代**：交易ネットワークと文明間交流
