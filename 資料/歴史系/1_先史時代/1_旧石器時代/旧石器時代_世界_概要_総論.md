# 旧石器時代 世界 概要 総論

## 概要

旧石器時代（Paleolithic Age）は、人類史における最初期の時代で、おおむね **約250万年前 〜 約1万年前（氷河期の終わり頃）** に相当する。人類が **打製石器** を主に用い、狩猟・採集・漁労を中心とする移動生活を営んでいたことが最大の特徴である。本節では時代の特徴・技術・文化的表現・代表的な化石人類・重要遺跡を中心に概観し、創作設定への応用可能性についても触れる。

## 詳細

### 特徴（総覧）

| 項目 | 内容 |
|------|------|
| **時期** | 約250万年前 〜 約1万年前 |
| **人類の種類** | ホモ・ハビリス、ホモ・エレクトス、ネアンデルタール人、クロマニョン人（ホモ・サピエンス） など |
| **生活様式** | 狩猟・採集・漁労（自然依存型の食料獲得）、移動生活が基本 |
| **主要道具** | 打製石器（チョッパー、ハンドアックス、石刃など）、木製・骨角製道具 |
| **住居** | 洞窟・岩陰・簡易な小屋 |
| **火の使用** | 約100万年前頃から定常的利用（暖房・採光・調理・捕食動物除け） |
| **言語の発達** | 簡易な音声言語の萌芽段階と推定 |
| **宗教・精神文化** | 埋葬・洞窟壁画・装身具など象徴表現の萌芽 |
| **気候** | たび重なる氷期と間氷期（更新世）への適応 |

### 代表的な人類と地域

| 人類 | 主な地域 | 代表的特徴 |
|------|---------|-----------|
| **ホモ・ハビリス** | アフリカ東部（オルドワン文化） | 最古級の石器（約250万年前） |
| **ホモ・エレクトス** | アフリカ→ユーラシア（北京原人・ジャワ原人） | 火の使用、アシュール文化のハンドアックス |
| **ネアンデルタール人** | ヨーロッパ・西アジア | ムステリアン文化、埋葬習慣 |
| **クロマニョン人（新人）** | ヨーロッパ | 上部旧石器文化、洞窟壁画・骨角器 |

### 重要な遺跡・文化

- **ラスコー洞窟（フランス）**：動物壁画（約2万年前）
- **アルタミラ洞窟（スペイン）**：バイソン壁画（約1.5万年前）
- **北京原人遺跡（周口店、中国）**：火の使用・旧石器文化層
- **オルドヴァイ峡谷（タンザニア）**：最古級石器群（オルドワン）

### 旧石器時代の終焉と次期への移行

約1万年前、気候の温暖化に伴い農耕・牧畜が萌芽し、新石器時代に移行する。この人類史上の画期は **「新石器革命」** と呼ばれ、定住化・余剰生産・社会分業・階層化といった大変革をもたらした。

## 創作への応用

- **世界観設定**：氷期末期の環境変動に翻弄される狩猟採集民の移動劇。
- **キャラクター造形**：洞窟壁画を描くシャーマン、火の保持を担う若者など、技術と儀礼を組み合わせた役割設定。
- **プロット装置**：火の獲得・喪失を巡る部族間対立や、祖霊信仰としての埋葬儀礼を物語の転換点に活用。
- **技術的制約**：打製石器の加工難度や石材の産地制限を通じた資源争奪。
- **精神文化**：壁画や装身具を「魔法の原初形態」として位置づけ、言霊・呪術体系へ発展させる導入。
