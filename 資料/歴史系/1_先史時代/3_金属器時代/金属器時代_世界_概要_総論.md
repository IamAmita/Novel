# 金属器時代 世界 概要 総論

## 概要

金属器時代は、**紀元前4500年頃から紀元前1000年頃まで**続いた時代で、人類が本格的に**金属器**を使用し始めたことが最大の特徴である。**銅器時代**から**青銅器時代**、そして**鉄器時代**へと発展し、武器・農具・装飾品など様々な用途で金属が活用された。この時代は、技術革新による生産力の向上、社会の階層化の進行、都市国家の形成など、文明の発展に大きく貢献した。

## 詳細

### 特徴（総覧）

| 項目 | 内容 |
|------|------|
| **時期** | 紀元前4500年頃 〜 紀元前1000年頃 |
| **主要技術** | 金属の精錬・加工技術（銅→青銅→鉄） |
| **生活様式** | 都市国家の形成、専門職の分化、交易の発達 |
| **主要道具** | 金属製武器・農具・装飾品、土器の改良 |
| **社会構造** | 階級社会の確立、王権の強化、軍隊の組織化 |
| **経済** | 余剰生産物の増大、長距離交易の活発化 |
| **宗教・文化** | 神殿建築、文字の発明、芸術の発達 |
| **技術革新** | 冶金技術、建築技術、文字体系の確立 |

### 金属器時代の区分

| 時代 | 時期 | 特徴 |
|------|------|------|
| **銅器時代** | 紀元前4500年〜紀元前3000年 | 自然銅の利用、初期の冶金技術 |
| **青銅器時代** | 紀元前3000年〜紀元前1200年 | 銅とスズの合金、高度な加工技術 |
| **鉄器時代** | 紀元前1200年〜紀元前1000年 | 鉄の精錬技術、大量生産可能 |

### 技術的革新

- **冶金技術**：銅の精錬から青銅合金、鉄の精錬へと発展
- **建築技術**：石造建築、都市計画、灌漑システム
- **文字の発明**：楔形文字、ヒエログリフ、線文字など
- **芸術・工芸**：金属細工、彫刻、壁画の高度化
- **軍事技術**：金属製武器、戦車、城壁の建設

### 社会・経済の変化

- **階級社会の確立**：王・貴族・平民・奴隷の階層化
- **都市国家の形成**：政治・経済・宗教の中心地
- **専門職の分化**：職人、商人、祭司、軍人など
- **長距離交易**：金属・宝石・織物などの交易ネットワーク
- **軍隊の組織化**：金属製武器による軍事力の向上

### 金属器時代の終焉と次期への移行

金属器時代は、**古代文明**の確立とともに終わる。文字の発明により歴史時代への移行が始まり、各地で都市国家や帝国が形成される。この時代の技術的・社会的基盤は、その後の古代文明の発展に大きく貢献した。

## 創作への応用

- **世界観設定**：金属器の導入による社会変革と、新旧技術の対立を描く。
- **キャラクター造形**：冶金職人、商人、軍人など、専門職の分化を反映した役割設定。
- **プロット装置**：金属資源を巡る争奪戦や、新技術の導入による価値観の変化を物語の転換点に活用。
- **社会構造**：階級社会の確立、都市国家の形成を通じた社会変革の描写。
- **技術革新**：冶金技術や建築技術を「魔法の体系化」として解釈し、技術・呪術体系の構築に応用。
