# 先史時代 世界 概要 総論

## 概要

先史時代（せんしじだい）は、人類がまだ文字を持たず、石器・土器・遺跡・化石など考古学的・人類学的資料によってのみその営為を知ることのできる時代である。本稿では約660万年前のヒト科出現から**金属器の普及期（銅器・青銅器・鉄器：紀元前4500年〜紀元前1000年頃）**までを扱い、その過程で各地域における初期文字（最古例はメソポタミア楔形文字、紀元前3500年頃）の誕生も含めつつ、狩猟採集社会から農耕牧畜社会・都市国家へ至る技術と社会変容を概観する。

## 詳細

### 時代区分と主な特徴

| 区分 | 年代（目安） | 技術・社会的特徴 |
|------|--------------|--------------------|
| 1. 人類以前〜前期旧石器以前 | 〜約660万年前 | 最古のヒト科化石（サヘラントロプス）。石器出現前の段階。 |
| 2. **旧石器時代** | 約250万年前〜約1万年前 | 打製石器の発達、火の利用確立、ネアンデルタール人・ホモ・サピエンスの出現と拡散、洞窟壁画。 |
|  2-1. 下部旧石器 | 〜約30万年前 | オルドワン・アシュール文化、ホモ・エレクトスのユーラシア進出。 |
|  2-2. 中部旧石器 | 約30万年前〜約5万年前 | 火の定常利用、ネアンデルタール人文化。 |
|  2-3. 上部旧石器 | 約5万年前〜約1万年前 | ブレード石器、骨角器、芸術表現、サピエンスの全世界拡散。 |
| 3. **中石器時代** | 約1万年前〜紀元前8000年頃 | 気候温暖化、マイクロリス、半定住化・漁撈。 |
| 4. **新石器時代** | 約1万年前（紀元前9000年頃）〜紀元前3000年頃 | 農耕牧畜開始、磨製石器・土器、集落と社会分業。 |
| 5. **金属器時代** | 紀元前4500年〜紀元前1000年頃 | 自然銅→青銅→鉄の利用拡大、武器・農具の多様化、文字体系の形成。 |

### 文化変容のキーワード

- **技術革新**: 打製石器 → 磨製石器 → 金属器
- **生業の転換**: 狩猟採集 → 半定住 → 農耕牧畜
- **社会組織**: 小規模バンド → 村落 → 余剰生産と分業
- **環境適応**: 氷期‐間氷期サイクルへの適応と移動
- **象徴表現**: 洞窟壁画・装身具・埋葬習慣にみる精神文化

## 創作への応用

- **世界観設定**: 狩猟採集民と定住農耕民が交錯する境界地域を舞台に対立と交流を描く。
- **キャラクター造形**: 移動を生業とする部族の語り部、初期農耕集落の治癒師など、生活様式の差異を反映した職能を設定。
- **プロット装置**: 新石器時代の技術革新（磨製石斧や土器）がもたらす価値観の変化を物語の転換点に利用。
- **象徴表現**: 洞窟壁画や装身具を“魔法の起源”として解釈し、呪術・信仰体系を構築。
- **環境ドラマ**: 氷期末期の気候変動をサバイバル要素として取り入れ、移住と適応を描写。
