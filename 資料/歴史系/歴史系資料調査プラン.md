# 歴史系資料調査プラン

## 概要
小説創作のための歴史系資料を体系的に調査・収集し、時代別・地域別に整理するための調査プラン。

## 調査対象期間・地域
- **期間**: 先史時代から現代まで（約300万年〜現在）
- **地域**: 全世界（ヨーロッパ、アジア、アフリカ、アメリカ大陸、オセアニア、極地）

## 調査優先度

### Phase 1: 基盤資料（最優先）
1. **神話・伝説**
   - 各地域の創世神話
   - 主要な神話体系（ギリシャ、北欧、エジプト、メソポタミア、インド、中国、日本など）
   - 英雄伝説・民間伝承

2. **古代文明の基盤**
   - メソポタミア文明（シュメール、アッカド、バビロニア）
   - エジプト文明
   - インダス文明
   - 黄河文明
   - 古代ギリシャ・ローマ

### Phase 2: 中世・近世の転換期
1. **中世ヨーロッパ**
   - 封建制度
   - 十字軍
   - 都市の発展
   - 大学の成立

2. **イスラム世界**
   - アラブ帝国
   - オスマン帝国
   - イスラム文化・科学

3. **東アジア**
   - 中国の王朝交替
   - 日本の平安・鎌倉・室町時代
   - 朝鮮半島の歴史

### Phase 3: 近代化の過程
1. **産業革命**
   - イギリス産業革命
   - 技術革新
   - 社会変革

2. **市民革命**
   - アメリカ独立革命
   - フランス革命
   - その他の革命運動

3. **帝国主義時代**
   - 植民地支配
   - 世界大戦への道

### Phase 4: 現代史
1. **世界大戦**
   - 第一次世界大戦
   - 第二次世界大戦
   - 戦間期

2. **冷戦時代**
   - 東西対立
   - 核開発競争
   - 地域紛争

3. **現代**
   - グローバリゼーション
   - 情報革命
   - 環境問題

## 調査項目詳細

### 各時代共通の調査項目
1. **政治・社会制度**
   - 統治システム
   - 階級制度
   - 法体系

2. **経済・技術**
   - 主要産業
   - 交易・商業
   - 技術革新

3. **文化・宗教**
   - 主要宗教
   - 芸術・文学
   - 哲学・思想

4. **軍事・外交**
   - 戦争・紛争
   - 外交関係
   - 軍事技術

5. **日常生活**
   - 衣食住
   - 教育
   - 娯楽

## 調査方法

### 1. 文献調査
- **学術書**: 専門的な歴史研究書
- **一般書**: 入門書、概説書
- **史料集**: 一次史料、二次史料
- **百科事典**: 信頼性の高い百科事典

### 2. オンライン調査
- **学術データベース**: JSTOR、Project MUSE
- **デジタルアーカイブ**: 各国の国立図書館、博物館
- **専門サイト**: 歴史研究機関のウェブサイト

### 3. 視覚資料
- **地図**: 歴史地図、地形図
- **絵画・彫刻**: 当時の美術作品
- **建築**: 遺跡、建造物
- **写真**: 近代以降の記録写真

## 資料整理方法

### ファイル命名規則
```
[時代]_[地域]_[項目]_[詳細].md
例: 古代_東アジア_政治制度_中国王朝.md
```

### 資料構造
1. **概要**: 基本的な情報
2. **詳細**: 具体的な内容
3. **参考文献**: 情報源
4. **関連項目**: 他の時代・地域との関連
5. **創作への応用**: 小説での活用方法

## 品質管理

### 情報の検証
- 複数の情報源での確認
- 最新の学術研究の参照
- 専門家の意見の確認

### 資料の更新
- 定期的な情報の見直し
- 新しい発見・研究の反映
- 創作への応用方法の改善

## 創作への応用

### 世界観構築
- 歴史的事実を基にした架空世界の創造
- 異なる時代・地域の要素の組み合わせ
- 魔法・ファンタジー要素との融合

### キャラクター設定
- 歴史的人物の研究
- 時代背景に基づく性格・行動の設定
- 社会的地位・職業の設定

### ストーリー展開
- 歴史的事件を基にしたプロット
- 時代背景を活かした設定
- 文化的背景を活かした描写

## 注意事項

1. **歴史的公正性**: 偏見のない客観的な記述
2. **文化的配慮**: 各文化への敬意と理解
3. **創作の自由**: 歴史的事実を基にしつつ、創作の自由を保つ
4. **継続的学習**: 新しい発見・研究への対応
